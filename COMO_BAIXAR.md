## 📋 Método Alternativo: Via Interface do GitHub

Se os links diretos não funcionarem, siga estas etapas:

### Passo 1: Acessar o Repositório
Vá para: https://github.com/gustavomachaddo-web/teste

### Passo 2: Mudar para a Branch Correta
1. Clique no dropdown de branches (normalmente mostra "main")
2. Digite ou selecione: `copilot/create-strategic-plan-pf`
3. Clique para mudar

### Passo 3: Baixar o Arquivo
1. Clique no arquivo desejado (ex: `Plano_Estrategico_PF.docx`)
2. Na página do arquivo, procure o botão "Download" no lado direito
3. Clique em "Download" para baixar o arquivo

## 💻 Método Avançado: Via Git

Se você tem Git instalado no seu computador:

```bash
# Clone o repositório
git clone https://github.com/gustavomachaddo-web/teste.git

# Entre na pasta
cd teste

# Mude para a branch correta
git checkout copilot/create-strategic-plan-pf

# Os arquivos estarão disponíveis na pasta
```
